Ionizing source
################

MAPPINGS can model the nebula around the stars, the AGNs and the self-defined ionizing sources. 
The current MAPPINGS code provides 8 stellar libraries, 3 AGN libraries, 1 local empirical interstellar radiation field, and two formts of input files for the self-defined source.
