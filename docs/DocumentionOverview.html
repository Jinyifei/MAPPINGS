Documentation Center for Mappings


Documentation for Mappings is currently sparse, and will hopefully improve over time.


  • Doxygen
    • The source code does not currently have Doxygen headers, but a working Doxygen configuration file can be found in the doxygen subdirectory
    • Assuming you have doxygen and grahphviz installed, one can create caller diagrams for mappings, by issuing the command  doxygen mappings_docs.config
    • Once you have done this, you can find the starting point to doxygen here.
