Documentation Center for Mappings


Documentation for Mappings is currently sparse, and will hopefully improve over time.

Note:  Documentation is an ongoing effort, and is not up to date.

At present the main resources are as follows:

  • A draft version of a cookbook which describes how to install Mappings and run a first photoinisztion model
  • A Sphinx repository, which ultimately will be the main document ion for the Mapping codes
    • This is part of the Mapings distribution.  All of the files are tracked in git
    • (Ultimately we want this avalialble on ReadtheDics)
    • This documentation needs to be updated when the code changes (obviously)
    • Instructions on how to do the updates are locally is here
    • It requires a software package known as sphinx
    • The command to generate the repository is currently:
      • cd docs/sphinx/; make html
  • Doxygen
    • The source code does not currently have Doxygen headers, but a working Doxygen configuration file can be found in the doxygen subdirectory
    • Assuming you have doxygen and grahphviz installed, one can create caller diagrams for mappings, by issuing the command  doxygen mappings_docs.config
    • Once you have done this, you can find the starting point to doxygen here.
