\code -- all scripts 
	0_run_MAPPINGS_grid.py -- assign all input and run the code by python 
		should assign 
			number of cpus to use
			working directory
			number of itertions 
			Table_log_OH_12_Z_and_depletion.csv table
			and paramters
				log10(U(H)), Press_P/K, and abund are three paramters contained 
					in both NLR and HII models
				E_peak, Gamma, and p_NT are three free paramters of OXAF and should 
					be assigned for NLR models
				abundance indicates the 12 + log(O/H) and should correspond to 
					abundance files, depletion files, and Table in \custom_inputs folder
					the abundance should also correspond to metallicity of stellar spectra
					for HII models
				dust_scenario indicates dust free, dust depletion, and dust destruction scenario
					this paramter choose one dictionary from input_templates.py as the input of
					MAPPINGS
			MAPPINGS information containing version, directory, and executable_name
			you could also run a local test for one grid point and should assign your local 
				MAPPING directory and working directory
	1_Post_process_grid.py -- make the emission line files based on the output of MAPPINGS
		should assign the working path, output file name, file of target line names, blend
			line names, and the parameter names, which should be exactly the same as the parameters
			listed in 0_run_MAPPINGS_grid.py
		the code output a .csv file with each line a combination of free parameters and all emission
			line flux normalized by Hb
	grid_caller.py -- the main code to run MAPPINGS, it will be called by 0_run_MAPPINGS_grid.py
	input_templates.py -- contain input templates for MAPPINGS with different dust scenarios and 
		end conditions.
		the input parameters specified in 0_run_MAPPINGS_grid.py are marked as 'blank' and will be 
			filled when running the code
		please note that all templates except for DN_99 are using plane parallel geometry, so that 
			the following paramter suite will be changed if you are using spherical geometry
	Linelist_for_results.csv -- the file list all line to be output in 1_Post_process_grid.py
		should contain wavelength, species and the name shown in the output file
	Linelist_blended_lines_for_results.csv -- the list of blend lines
		all the components of each blended lines should already be included in the 
			Linelist_for_results.csv
	oxaf.py -- OXAF model of AGN spectra, called in grid_caller
		doesn't have it in HII models.





\custom_inputs -- abundance and depletions files
	\abundances -- abundance files generated by gczeta.rb
		gczeta.rb -- generate GC abunance files given zeta_O in zeta_GC.txt
		.abn -- abundance files with the name indicating the linear zeta_O
		GC_Masterv2.6.3.txt -- list fiducial abundance of 30 elements and Xi(Fe)
			for more information, refer to Nicholls et al. 2017
		zeta_GC.txt -- input file for gczeta.rb
			containing Zetas: log(linear)
					   Base: O(Fe)
					   and list all zetas you want with the chosen base and scale
	\depletions -- depletion files for dust depletion 
		.txt -- depletions for 30 elements log10(gas_X/total_X)
			the name indicates the iron depletion
			each file should correspond to the abundance file in \abundances folder
		Generate_depletion_files.py -- generate the depletion files
			should assign 12+log(O/H) in list_12OH list, the oxygen abundance should 
				correspond to the abundance files in \abundances folder
	Table_log_OH_12_Z_and_depletion.csv -- file contain abundance and depletion informations
		this is the file where the code looks for corresponding abundance files and 
			depletion files
		12+log(O/H) nebular -- the oxygen abundance assigned in the code
		linear_zeta_O_nebular -- corresponding linear zeta_O, used to look for abundance file
		Z/Zsun -- corresponding Z_total/Z_sun, useless for AGN model, used to look for stellar
			spectra
		log10(Fe_free/Fe_tot) -- corresponding iron depletion, used to look for depletion file
	\spectra -- contains stellar ionizing spectra (no this folder in AGN model)
		name indicates the Z_total/Z_sun, should be consistent with that in 
			Table_log_OH_12_Z_and_depletion.csv file.



\grids -- empty at first
	outputs of each running (in its own folder, named by intrinsic parameters)
		, containing output of MAPPINGS, screen stand out of running (.txt), and 
		all the input parameters of the running (.sh)



\scripts -- empty at first
	containing the input paramters after the running (one for each running),
		<.sh> file, the same as the <.sh> file in \grids folders



\spectra -- empty at first
	useless for HII grids
	containing the ionizing spectra files of the AGN grids, the output of OXAF after the running
